# Bản đồ tính năng Owner

| Feature | Trách nhiệm |
|---|---|
| dashboard | KPI điều hành có truy xuất nguồn |
| appointments | Lịch ngày/tuần/tháng, walk-in, cọc, trạng thái |
| customers | Hồ sơ, lịch sử, consent, ảnh |
| workflow | Công đoạn, phân công, tạm dừng, event history |
| services | Giá, thời lượng, vật tư, commission |
| employees | Hồ sơ, ca, vai trò, quyền, hiệu suất |
| inventory | Sản phẩm, lô, hạn dùng, nhập xuất, cảnh báo |
| pos | Hóa đơn, thanh toán, tip, hoàn tiền, đóng ca |
| finance | Thuế cấu hình, chi phí, lãi gộp ước tính |
| reports | Bộ lọc ngày/tuần/tháng/quý/năm và drill-down |
| devices | Duyệt, thu hồi, trạng thái đồng bộ |
| backup | Export/import mã hóa và xác nhận restore |
| assistant | Gemini server-side, quyền và cost cap |
| settings | Cấu hình salon, VND, timezone, chính sách |

Không có Employee App hoặc route nhân viên trong Giai đoạn 1.
